# Licencias de arte y tipografías

El arte (cartas, dorsos, avatares, sellos, textura de papel) está hecho en código para este proyecto: SVG y CSS propios, sin assets externos.

## Tipografías (servidas desde el bundle, paquetes de Fontsource)

| Fuente            | Uso                    | Licencia                  | Paquete                       |
| ----------------- | ---------------------- | ------------------------- | ----------------------------- |
| Oswald (variable) | Palabras de las cartas | SIL Open Font License 1.1 | `@fontsource-variable/oswald` |
| Special Elite     | Logo, sellos, títulos  | Apache License 2.0        | `@fontsource/special-elite`   |
| Inter (variable)  | Interfaz               | SIL Open Font License 1.1 | `@fontsource-variable/inter`  |
